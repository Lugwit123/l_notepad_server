来源 sources

知识库 kb
把范围限定到某一个知识库（相当于「来源=仅知识库」再加库过滤）；点结果列表上方的库标签也能快速筛选。
重排 rerank
用本机交叉编码器对候选块再排一次序，更准但更慢；服务端未配置时该项无效（默认即按全局配置）。
每页条数 / 分页 limit · offset
每页可设 20/50/100/200；底部「上一页/下一页」翻页。
查询语法
空格分段（段间 AND）；"引号"表示精确短语（无结果自动回退模糊）；单个汉字按前缀匹配；英文/数字按整词、大小写不敏感。
"自动"到底是什么
auto = 先词法、零命中再语义：先用倒排索引（毫秒级）搜；只有当一条都没命中时，才自动改用语义检索兜底。既有词法命中就快，长句/自然语言也不会"无命中"，所以是默认推荐。
